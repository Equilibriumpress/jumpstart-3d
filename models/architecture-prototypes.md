# Architecture variety test

Three native JumpStart 3D experiments generated with the existing JS3D CAD engine, with no new modelling engine.

- `test-grachtenpand` - classic Amsterdam house: box, roof, window repetitions.
- `test-drieboogsbrug` - three real arch openings cut with a cylinder and boolean group, plus rotations.
- `test-koepelpaviljoen` - advanced circle sketch / extrusion, classical columns and a hemispherical roof.

All use original CAD techniques and aim for standalone, editable projects and real viewport screenshots. They are illustrative test models and should not be mistaken for accurate reconstructions.

Experiments have `published:false` and stay outside the public Pages catalog until approved. Open the PR to review generated preview PNGs. No changes to the core CAD engine.
